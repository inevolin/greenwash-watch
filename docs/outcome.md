# Outcome rubric (yes/no; pass = all yes)
1. Does every assessed claim quote the brand's own words, with a fetched URL and date?
2. Does every verdict (holds up / unsubstantiated / misleading) cite at least one independent source that contradicts or supports it, plus the relevant rule (CMA code, or EU 2024/825 / UCPD)?
3. Is the wording defamation-safe: framed as "our assessment", with no allegations of intent or dishonesty beyond what a cited ruling found, and with "unsubstantiated" used where evidence is lacking?
4. Did the run process the ~6 brands next in rotation, report only claims new within the relative window, and update brand memory?
5. Is the Green Claims Directive described accurately (pending proposal, withdrawal announced, not law), with no fabricated rulings or URLs?
6. On the eval set, does the agent rate each ruled claim misleading or unsubstantiated for a reason consistent with the ruling? (Weekly: is the leaderboard built only from stored, cited verdicts?)
